
# Salaries Prediction

Projet MLOps réalisé dans le cadre du Lab 1 : Git et GitHub.

## Objectif

Apprendre à organiser un projet Python pour le Machine Learning et à collaborer avec Git et GitHub.

## Installation

Cloner le dépôt :

```bash
git clone https://github.com/paolo-fx/salaries_prediction.git
cd salaries_prediction
```

Installer les dépendances :

```bash
uv sync
```

## Structure du projet

- `src/` : code source Python
- `tests/` : tests unitaires, d'intégration et end-to-end
- `notebooks/` : expérimentations Machine Learning
- `docs/` : documentation technique
- `tasks/` : automatisation des commandes
- `.github/` : configuration de GitHub Actions

## Technologies

Python, uv, Git et GitHub.

## Statut

Structure initiale créée. Les fonctionnalités Machine Learning et les workflows automatisés restent à développer.
